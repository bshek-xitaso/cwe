# cwe

This repo provides a rust library to access the [Common Weakness Enumeration (CWE)](https://cwe.mitre.org/) data relevant to [Common Security Advisory Framework (CSAF)](https://www.oasis-open.org/committees/tc_home.php?wg_abbrev=csaf) in a convenient way. 

The CWE is a community-developed list of software and hardware weakness types.
